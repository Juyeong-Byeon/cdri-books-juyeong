# ADR-0005: /api/books로 통일한 Vite·Cloudflare 서버 프록시

- **상태**: 승인 (Accepted)
- **결정·개정 일자**: 2026-10-22
- **결정자**: 변주영

## 배경

API 키를 Git에 커밋하지 않는 것과 브라우저에 전달하지 않는 것은 별개다. Vite의 클라이언트 환경 변수에 키를 넣으면 번들과 네트워크 요청에서 확인할 수 있다. 개발과 배포 환경 모두 서버에서 카카오 요청의 인증 헤더를 구성해야 한다.

기존 개발 프록시는 `/api/search/book`, 배포 Function은 `/api/books`를 사용한다. 또한 개발 프록시의 고정 rewrite가 검색 쿼리를 제거하는 문제가 리뷰에서 재현되었다.

## 결정

- 브라우저는 개발·배포 모두 같은 출처의 `GET /api/books`를 호출한다. 클라이언트에 환경별 API 경로 분기를 두지 않는다.
- 개발은 Vite 서버 프록시, 배포는 `functions/api/books.ts`의 Cloudflare Pages Function으로 처리한다.
- 서버의 업스트림은 `https://dapi.kakao.com/v3/search/book`으로 고정한다.
- 경로만 변환하고 URL 인코딩된 `query`, `target`, `sort`, `page`, `size`를 보존한다. 필수값과 허용값은 검증한다.
- 로컬에서는 서버 전용 `KAKAO_REST_API_KEY`를 환경 또는 Git에서 제외된 `.env.dev`로 주입한다. `npm run dev`는 Vite의 `dev` 모드로 해당 파일을 읽는다. 배포에서는 Cloudflare secret 바인딩으로 제공한다.
- 키를 `VITE_` 변수, 클라이언트 코드, URL, 응답, 로그에 포함하지 않는다. 키가 없으면 명시적인 구성 오류를 반환한다.
- 개발·배포의 정상 응답과 오류 의미를 맞추고, HTTP 상태를 클라이언트가 구별할 수 있게 한다.
- 배포 환경에서 실제 검색과 추가 페이지 로딩까지 검증한다. 정적 빌드 성공만으로 API 연동 완료로 판단하지 않는다.

## 대안과 선택 이유

| 대안                                      | 평가                                                                         |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| 브라우저에서 카카오 직접 호출             | 구성이 단순하지만 인증 키가 클라이언트에 전달된다.                           |
| 별도 Express 등의 서버                    | 서버 제어가 쉽지만 별도 실행·배포 관리가 늘어난다.                           |
| Vite 프록시 + Cloudflare Functions (선택) | SPA 구성을 유지하면서 기존 배포 방향을 활용한다.                             |
| 개발 프록시만 구현                        | 로컬 평가에는 사용할 수 있지만 선택한 배포 검색 검증 범위를 충족하지 못한다. |

## 결과와 트레이드오프

개발과 엣지 런타임의 두 구현이 같은 API 계약을 유지해야 한다. 같은 출처 호출은 브라우저 CORS 구성을 단순하게 하지만 업스트림 연결 실패·인증 오류·할당량 문제까지 해결하지는 않는다. 공개 프록시를 통한 키 사용량 문제도 키 은닉과 별개다.

`vite preview`는 정적 빌드를 확인하는 서버이며 Pages Functions를 실행하지 않는다. 실제 Function은 지원되는 Cloudflare 실행 환경 또는 배포 환경에서 따로 검증한다. 호스팅만으로 응답 캐싱이 설정됐다고 가정하지 않는다.

## 구현 시 확인

- 기존 개발 경로를 통일하고, 쿼리를 보존하도록 rewrite를 수정한다.
- 개발·배포에서 한글 검색어와 페이지·검색 대상이 업스트림에 전달되는지 확인한다.
- 키 누락·인증 실패·업스트림 실패를 구분하고, 브라우저에 키가 전달되지 않는지 확인한다.
- 배포·비밀값 등록·실제 호출은 미완료 검증 항목으로 남기고, 수행 후 결과를 기록한다.
